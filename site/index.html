# PRD: Retail Inventory Tracker

## Problem Statement
Small retailers lose track of physical stock discrepancies between point-of-sale transactions and supplier restocks without expensive ERP software.

## Objective
A fast, single-screen desktop inventory portal for cashiers to log stock updates with sub-second lookups.

## Core Data & Entity Model
| Entity | Key Attributes | Relationships |
|---|---|---|
| Product | id (uuid), sku (unique), name, price | 1-to-many Movements |
| StockMovement | id, product_id, quantity, type (IN/OUT) | belongs-to Product |
| StoreLocation | id, name, code | 1-to-many Stocks |

## Constraints & NFRs
- p95 search latency < 150ms over 50,000 SKUs.
- Full offline resilience for uncommitted scans.
- Role-based permissions: Cashier (read/log) vs Owner (admin).

# Task 02: SKU Barcode Search API

## Source
PRD section: "Core Data & Entity Model" and "Constraints"

## What this delivers
A cached lookup endpoint that returns product metadata and current stock level by exact SKU or barcode scan in < 100ms.

## Acceptance Criteria
- [ ] GET /api/products/search?q=:sku returns 200 with product object
- [ ] Returns 404 when SKU does not exist
- [ ] Response payload is sanitized; cached in Redis for 60s

## Verification
- [ ] Tests pass: `npm test tests/api/search.test.ts`
- [ ] Build succeeds: `npm run build`
- [ ] Performance check: response time < 100ms
- [ ] Security check: input validation against SQLi / injection

## Blocked by
Task 01 (Database Schema & Migration)

# Design Specification: Retail Inventory Desk

## 1. Visual Thesis & Audience
- Product Job: Rapid barcode scanning and real-time stock adjustment.
- Operating Scene: Retail counter with ambient fluorescent lighting; keyboard-only operation.
- Aesthetic Character: Utilitarian, sharp precision, high information density.

## 2. Design Tokens
- Color Palette:
  - Base Obsidian: `#0D1117` (Deep dark background)
  - Surface Row: `#161B22` (High contrast table row)
  - Primary Accent: `#2EA043` (Positive stock / in)
  - Warning Accent: `#DA3633` (Low stock alert)
  - Text Contrast: `#F0F6FC` (Ratio 13.5:1 against base)
- Typography:
  - UI Labels: Plus Jakarta Sans, 13px / 1.4 weight 500
  - Stock Numbers & Barcode: JetBrains Mono Tabular

## 3. Responsive Breakpoints
- Desktop (1280px+): Dual-panel scan table with quick keypad
- Mobile (375px): Single-column emergency stock tally with bottom barcode trigger

## 4. Component Interactive States
- Scan Row: default, active focus ring (#388BFD 2px solid), error flash (#F85149)
